# Repository agent instructions

Read [common.md](common.md), then read the document for your role:

- **Main agent:** If you own the user's overall task and coordinate its delivery, read [main-agent.md](main-agent.md).
- **Subagent:** If another agent assigned you a bounded task, including review, read [subagent.md](subagent.md).

Determine whether you are a main agent or subagent from the runtime and assignment, not from the availability of delegation tools. Read only the applicable role document; do not load every guide by default.

A subagent assigned coordination responsibilities must read [main-agent.md](main-agent.md) before dispatching or reassigning children, while retaining its original assignment boundaries.

The shared and applicable role documents are project instructions. File links are references, not a request to load every linked document; read the material required for the assigned work.
